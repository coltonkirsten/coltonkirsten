## Building now

### [a12s](https://github.com/coltonkirsten/a12s)
Run AI coding agents (Claude Code, Codex) as isolated, durable computers on Docker. One file declares them, and TypeScript and Python SDKs drive them.

```sh
brew install coltonkirsten/tap/a12s
```

Examples: [a12s-cookbook](https://github.com/coltonkirsten/a12s-cookbook)
